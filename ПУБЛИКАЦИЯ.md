# Как опубликовать визитку и блог

Как назначить **одинесница.рф** визитке: [ДОМЕН.md](ДОМЕН.md)

Целевая схема:

- **одинесница.рф** — эта визитка (GitHub Pages)
- **blog.одинесница.рф** — блог (Тильда)
- **одинесница.рф/blog** — редирект на поддомен блога (файл `blog/index.html` уже в репозитории)

Сейчас домен **одинесница.рф** ещё на Тильде (`ns1.tildadns.com` / `ns2.tildadns.com`). Пока не переключайте его, если блог должен оставаться доступным по старому адресу.

Репозиторий: [github.com/AnastasiaSin1C/odinesnitsa](https://github.com/AnastasiaSin1C/odinesnitsa)  
(старый адрес `-------` GitHub перенаправляет сюда)

## Сейчас: служебный адрес GitHub Pages

Сайт должен открыться здесь:

**https://anastasiasin1c.github.io/odinesnitsa/**

### 1. Запушить последний коммит

Ветка `main` может быть на один коммит впереди origin — редирект `/blog`. В Cursor: Source Control → Push.

### 2. Сделать репозиторий публичным

Settings → General → Danger Zone → Change repository visibility → **Public**

На бесплатном GitHub закрытый репозиторий Pages наружу не отдаёт.

### 3. Включить Pages

Settings → Pages

- Source: **Deploy from a branch**
- Branch: **`main`**
- Folder: **`/ (root)`**
- Save

Через 1–2 минуты нажать **Visit site**. Это и есть служебный домен, пока одинесница.рф не трогаем.

## Потом: привязать одинесница.рф к визитке

После этого Тильда по адресу одинесница.рф перестанет открываться. Блог заранее перенесите на поддомен (следующий раздел).

### 1. Вернуть DNS с Тильды регистратору

В панели регистратора домена (часто Рег.ру): одинесница.рф → управление NS.

Сменить NS с `ns1.tildadns.com` / `ns2.tildadns.com` на **стандартные NS регистратора**. Подождать обновления (минуты–часы).

Пока NS у Тильды, записи GitHub не заработают.

### 2. Прописать A-записи визитки

Для самого домена **одинесница.рф** (хост `@`):

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

Лучше сразу и AAAA:

| Тип | Имя | Значение |
|---|---|---|
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |

Если нужен **www**:

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `www` | `anastasiasin1c.github.io` |

Удалить старые A/CNAME, которые смотрели на Тильду. Не оставлять wildcard `*`.

### 3. Указать домен в GitHub

Settings → Pages → Custom domain:

```text
xn--80ahdlb2abd5a6c.xn--p1ai
```

Это Punycode для **одинесница.рф**. Кириллицу GitHub часто не принимает.

Save. GitHub сам добавит файл `CNAME` — его не удалять.

Когда DNS check станет зелёным — включить **Enforce HTTPS**. Сертификат может появиться до часа.

Проверка: https://одинесница.рф — должна открыться визитка, не Тильда.

## Потом: блог на blog.одинесница.рф

Блог сейчас на Тильде по адресу `/blog`. Его нужно перенести **до** или сразу вместе с отключением Тильды на основном домене.

### 1. Тильда

В проекте блога (тот, что открывается как `/blog`):

1. Настройки сайта → Домен
2. Указать `blog.одинесница.рф` (без `https://` и без `/blog` на конце)
3. Сохранить и **скопировать IP**, который покажет Тильда
4. Убрать привязку как папки `одинесница.рф/blog`

Главный сайт Тильды на одинесница.рф после переноса визитки можно отключить.

### 2. DNS — запись для поддомена

В той же зоне одинесница.рф (уже у регистратора, не у Тильды):

| Тип | Имя | Значение |
|---|---|---|
| A | `blog` | IP из настроек Тильды |
| A | `www.blog` | тот же IP, если Тильда его просит |

В панели, которая не принимает кириллицу: хост всё равно `blog`, зона — `xn--80ahdlb2abd5a6c.xn--p1ai`.

Через несколько часов в Тильде должно появиться, что домен подключён. Открыть https://blog.одинесница.рф/

Старый адрес **одинесница.рф/blog** после публикации визитки сам перекинет на поддомен.

## Обычная работа после публикации

Правите файлы → коммит → `git push` в `main`. Через минуту обновляется и github.io, и одинесница.рф (когда домен уже привязан).
